# Qt Camera

A simple desktop camera application built with **Python, PyQt5, and OpenCV**.

## Features
- Live webcam streaming
- Capture and save images
- Timestamp-based image filenames
- Interactive capture button with hover effects

## Requirements
- Python
- PyQt5
- OpenCV

## Installation

```bash
pip install PyQt5 opencv-python
```

## Run

```bash
python camera.py
```

Captured images are saved in the `captured-images/` directory.
